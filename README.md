# ครัวสุขภาพ – ด่านอาหารเช้า (ต้นแบบ)

เกมเว็บ 2D ด้วย HTML + CSS + JavaScript + **Phaser 3** สอนการเลือกอาหารสำหรับเด็กที่เป็นโรคไต
(มีเฉพาะด่านที่ 1 "อาหารเช้า")

## วิธีเปิดด้วย VS Code + Live Server
1. เปิดโฟลเดอร์ `kidney-kitchen` ใน VS Code (File > Open Folder)
2. ติดตั้งส่วนขยาย **Live Server** (Ritwick Dey) จากแท็บ Extensions
3. คลิกขวาที่ `index.html` > **Open with Live Server** (หรือกด "Go Live" มุมล่างขวา)
4. เบราว์เซอร์จะเปิดที่ `http://127.0.0.1:5500` ต้องต่ออินเทอร์เน็ตเพื่อโหลด Phaser และฟอนต์จาก CDN

## วิธีเล่น (มุมมองด้านบน เดินได้ 4 ทิศ)
| ปุ่ม | หน้าที่ |
|---|---|
| A / D / W / S หรือ ลูกศร | เดิน ซ้าย / ขวา / ขึ้น / ลง |
| E | เก็บวัตถุดิบ (ต้องยืนใกล้) / จัดอาหารที่จานสีเขียว (ต้องยืนใกล้) |
| F | ดูข้อมูลโภชนาการของวัตถุดิบที่อยู่ใกล้ |
| Esc | ปิดหน้าต่าง (ยกเว้นหน้าสรุป) |

**บนมือถือ:** ใช้จอยสติ๊กซ้ายล่างเดิน และปุ่ม E / F ขวาล่าง (แสดงอัตโนมัติบนจอสัมผัส) ควรเล่นแนวนอน
ทดสอบมือถือผ่าน Live Server: ต่อมือถือกับคอมเครื่องเดียวกันใน Wi-Fi เดียวกัน แล้วเปิด `http://<IP ของคอม>:5500`

เก็บวัตถุดิบ → ดูข้อมูล → เดินไปจานสีเขียว → เลือกให้ครบ 3 อย่าง → ยืนยัน → ดูสรุปผลรวมสารอาหาร → เล่นใหม่
แถบเก็บวัตถุดิบอยู่ด้านขวา ขณะเปิดหน้าต่างใดๆ ตัวละครจะหยุดเดินและเก็บของไม่ได้

## โครงสร้างโค้ด (`game.js`)
- `FOOD_DB` ฐานข้อมูลวัตถุดิบเดียว ใช้ร่วมกันทั้งหน้าข้อมูล หน้าจัดจาน และหน้าสรุป
- `LEVELS` นิยามด่าน (วัตถุดิบ ตำแหน่งบนเคาน์เตอร์ ตำแหน่งจาน จำนวนที่ต้องเลือก) เพิ่มด่านกลางวัน/เย็นได้โดยเพิ่ม object ใหม่
- `sumNutrients()` คำนวณผลรวมจากวัตถุดิบที่เลือกจริง และจะ error หากปริมาณอ้างอิงไม่ตรงกัน
- `counterSlots` แก้ตำแหน่งวัตถุดิบ (แทนจุดสีชมพูใน UX/UI) · `CFG` ปรับความเร็วและระยะเก็บ/โต้ตอบ
- เปลี่ยน Emoji เป็นรูปภาพ: ใส่ path ที่ `sprite` ของวัตถุดิบ เช่น `sprite: 'assets/rice.png'`

## ระบบประเมินและแจ้งเตือน
- แต่ละวัตถุดิบมี "ปริมาณที่กินจริง" (เช่น ไข่ 1 ฟอง = 50 g) คำนวณ = ค่าต่อ 100 g × กรัมที่กิน ÷ 100 แล้วบวกกันเฉพาะ 3 อย่างที่เลือก
- เกณฑ์ต่อมื้อ = เกณฑ์ต่อวัน × 25% (แก้ที่ `PROFILE` ใน `game.js`) โซเดียม/โพแทสเซียม/ฟอสฟอรัสเป็น "ห้ามเกิน" ส่วนพลังงาน/โปรตีนเป็น "ช่วงที่เหมาะสม"
- ไฟจราจร: เขียว ≤ 70% ของเกณฑ์ · เหลือง 70–100% (หรือ ต่ำกว่าช่วง) · แดง เกินเกณฑ์
- จุดที่เตือน: (1) ตาราง % ในหน้าข้อมูลวัตถุดิบ (2) มาตรวัดสดในหน้าต่างจัดจาน + ข้อความป๊อปอัปเมื่อใส่แล้วเกิน (3) หน้าต่างถามซ้ำก่อนยืนยันถ้า "ยังไม่เหมาะ" (4) หน้าสรุปแสดงตารางคำนวณ คำตัดสิน และคำแนะนำสลับวัตถุดิบ

## ข้อสำคัญเรื่องข้อมูลโภชนาการ
ค่าโภชนาการ ปริมาณที่กิน และ **เกณฑ์เตือนทั้งหมด** เป็น **ข้อมูลตัวอย่างสำหรับทดสอบระบบ** ยังไม่ผ่านการตรวจสอบกับแหล่งข้อมูลทางการ
และ **ไม่ใช่คำแนะนำทางการแพทย์** ก่อนใช้งานจริงควรแทนที่ด้วยค่าจากฐานข้อมูลที่เชื่อถือได้ (เช่น ตารางแสดงคุณค่าทางโภชนาการไทย) และให้แพทย์/นักกำหนดอาหารตรวจสอบ
แล้วเปลี่ยน `verified: true`
